Двадцать два дополнения, которые работают вместе и — кроме `dot-core` —
работают по отдельности. Каждое лежит в собственном репозитории под
[`modcommunity`](https://github.com/modcommunity), каждое поставляет одну папку
`addons/<имя>/`, и у каждого есть собственный набор безоконных тестов.

## Основа

| | Зависит от | |
| --- | --- | --- |
| [dot-core](/learn/godot/addons/dot-core) | — | Журналирование, возможности платформы, пути, настраиваемые ссылки на узлы, слоистая конфигурация, задачи с бюджетом на кадр, транспорты для мультиплеера, HTTP. |

## Платформа

| | Зависит от | |
| --- | --- | --- |
| [dot-cloud](/learn/godot/addons/dot-cloud) | dot-core | Доставка контента во время работы: подписанные манифесты, кэш с адресацией по содержимому, возобновляемые параллельные загрузки, монтирование пакетов с пространством имён. |
| [dot-auth](/learn/godot/addons/dot-auth) | dot-core | Вход по коду устройства через бэкенд, подписанные билеты подключения, серверная идентификация. |
| [dot-net](/learn/godot/addons/dot-net) | dot-core | Сетевой код: синхронизация тиков, битовый формат передачи, репликация состояния, интерполяция снимков, предсказание на клиенте, компенсация задержки, управление интересом. |
| [dot-server](/learn/godot/addons/dot-server) | dot-core, *опционально* dot-auth + dot-cloud | Выделенный сервер: консоль, RCON, запросы, права, модерация, голосования, модули, смена игры на лету. |
| [dot-user](/learn/godot/addons/dot-user) | dot-core | Профили, которые следуют за человеком между серверами, под псевдонимным идентификатором для каждой области. |
| [dot-user-avatar](/learn/godot/addons/dot-user-avatar) | dot-core | Аватары как данные: ограниченный документ, который сервер проверяет по схеме и правам, ни разу не загрузив меш. |
| [dot-platform](/learn/godot/addons/dot-platform) | dot-core, dot-server | Соединяет личность, профиль и аватар в один поток допуска и привязывает его к серверу. |

## Игровой слой

| | Зависит от | |
| --- | --- | --- |
| [dot-fps-controller](/learn/godot/addons/dot-fps-controller) | dot-core | Движение от первого лица: ускорение в духе Quake/Source, air-strafing, подъём по ступеням, приседание с проверкой потолка. Детерминированное и управляемое командами. |
| [dot-2d](/learn/godot/addons/dot-2d) | dot-core | Двумерный аналог: детерминированное движение сверху, тягой и по массе, пространственный хеш для тысяч сущностей и детерминированные поля рассыпания. |
| [dot-combat](/learn/godot/addons/dot-combat) | dot-core | Здоровье, урон и оружие: аналитические хитбоксы, детерминированный разброс, регистрация попаданий с компенсацией задержки. |
| [dot-loadout](/learn/godot/addons/dot-loadout) | dot-core | То, с чем игрок входит в матч, как документ, который сервер проверяет, не загружая никакого контента. Плюс детерминированные подбираемые предметы. |
| [dot-match](/learn/godot/addons/dot-match) | dot-core | Цикл матча: разминка, раунды, счёт, команды, появление и возрождение. Всё в тиках и движется одним вызовом. |
| [dot-ui](/learn/godot/addons/dot-ui) | dot-core | Экраны, HUD и меню без единого графического ресурса. Стек экранов, панель настроек, построенная из любого `DotConfig`, и переназначение клавиш с обнаружением конфликтов. |

## Жанровый набор

| | Зависит от | |
| --- | --- | --- |
| [dot-timer](/learn/godot/addons/dot-timer) | dot-core | Таймеры для спидранов: зоны, трассы, этапы, стили, повторы, рекорды. С точностью меньше тика, поэтому забеги на 64 Гц и 128 Гц сравнимы. 2D и 3D. |
| [dot-map](/learn/godot/addons/dot-map) | dot-core, *опционально* dot-cloud | Карты как контент, а не как сборки: каталог, ротация, номинации и голосование, и загрузчик, который тянет их через dot-cloud. |
| [dot-props](/learn/godot/addons/dot-props) | dot-core | Песочница: каталог создаваемых объектов, лимиты на игрока, стек отмены, физическая пушка и гравипушка. Авторитет — у сервера. |
| [dot-leaderboard](/learn/godot/addons/dot-leaderboard) | dot-core, *опционально* dot-auth | Таблицы рекордов, статистика по игрокам, рейтинговые очки, интерфейс хранилища и пакетный отправитель на бэкенд. |
| [dot-stats](/learn/godot/addons/dot-stats) | dot-core, *опционально* dot-auth | Статистика, которую игра объявляет один раз — счётчики, датчики, лучшие и худшие значения — и отправляет объединёнными приращениями. |
| [dot-voice](/learn/godot/addons/dot-voice) | dot-core | Голосовой чат: захват, сменный кодек, буфер джиттера на каждого говорящего и серверная маршрутизация всем, команде или в радиусе. |
| [dot-moderation](/learn/godot/addons/dot-moderation) | dot-core | Баны, кики, запреты чата и микрофона и предупреждения как один долговечный запись со сменным хранилищем. Публикует источники немоты и банов. |
| [dot-vote](/learn/godot/addons/dot-vote) | dot-core, *опционально* dot-server + dot-map | Голосование за то, что будет дальше, одним настраиваемым движком: rtv, номинации, четыре метода подсчёта, пять правил разрешения ничьей. |

<Callout type="info" title="«Опционально» значит «находится во время работы»">
Всё из колонки *опционально* разрешается утиной типизацией или через
[`DotRegistry`](/learn/godot/conventions#dotregistry-instead-of-autoloads).
Ни одно из этих дополнений не импортирует другое и не называет чужих
идентификаторов — потому что в GDScript скрипт, который лишь *упоминает*
отсутствующий `class_name`, не разбирается и утягивает за собой всё, что на него
ссылается.
</Callout>
